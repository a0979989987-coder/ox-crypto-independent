這一輪主要把必要工作移到空檔，下載總量沒有大幅減少。空檔階段多用約 2.4 MB 的程式／CSS／有效行情記憶體，訪問四工具後約只差 0.02–0.05 MB。heap 是 CDP 強制 GC 後主執行緒 JS heap，未涵蓋 worker、GPU 或實體手機總記憶體。回應本體 bytes 含測試固定資料，未量測真實 CDN Brotli 流量。

冷啟動原始紀錄逐項保存 JS／CSS resource duration／encodedBodySize、行情 queueMs／downloadMs／attempts、主執行緒 TaskDuration，以及首個顯示／有效資料／完整完成時間。暖機紀錄另有各次點擊的 CPU ms、請求數與本體 bytes；本輪沒有單獨量測 worker 運算耗時，不能用主執行緒時間代替它。
