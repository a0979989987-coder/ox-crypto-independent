# 加密板塊與連續回放（2026-10-07）

- 31 個一級板塊、226 個二級題材由 `sector-topics.js` 定義，`sector-taxonomy.js` 以交易所資料驗證。成分清單允許重疊；同名但不同專案的代號保留在候選清單，無法由 Bitget 合約資料確認身分時不納入計算。
- Bitget v3 線上加密 USDT 永續合約、相符 baseCoin 與正成交量 ticker 三項均通過才加入；每個群組需要至少兩筆完整的共同 K 線才能算出泡泡。選擇器展示 31 群及各二級題材的候選／已驗證數，畫布與排行只顯示有完整資料的群組。BTC 同時是 BTC／PoW 候選及相對報酬基準。重疊成分的成交占比不是全市場去重資金流。
- 冷啟動先讀記錄快照；背景共用行情排程低優先刷新並分批顯示。記錄快照由 `scripts/capture-crypto-tools.py` 擷取，和前端共用清單。若某筆行情失敗，留下錯誤和覆蓋數，不補零；下一次刷新可重試。
- 板塊輪動與主動買賣回放共用單一動畫時鐘，使用同一畫布以每幀補間位置、成交量對應的半徑與顏色。日期、排行及數值仍採真實完整期別；暫停後可續播，拖曳滑桿保留小數期別，切換或背景隱藏時取消動畫。
- 快照 `coins` 只保留先前記錄的 CoinGecko 市值及 `last_updated`，不將舊市值視為即時值；新成分沒有市值時沿用現有熱力圖的成交額或等大視圖。
- 本地可執行 `npm run build:tools && npm run check && npm test`。瀏覽器驗證：`npm run test:news-rotation`；CI 在 pull request 上會重跑。需要最新市場快照時，工作流程 `Capture crypto sector snapshot` 只上傳可檢查的 artifact，再明確加入此專案。

2026-10-07 擷取樣本：684 個候選代號，283 個 Bitget 合約通過驗證，283 筆 K 線成功；28 個一級板塊可算出泡泡。穩定幣、預測市場、DeSci 各只有一個合格合約，暫不計算板塊泡泡；來源更新後涵蓋數可能變動。
# 潮汐圖第二輪修正

- 手機圖上方的涵蓋與時間資訊移至圖下方，刻度靠左並縮小，圖面加高。
- 板塊輪動新增 30m、2h、6h、12h、1d；主動買賣依 Bitget 支援再加入 5m 與上述週期。日線在首次打開時以低優先權分批取得完整驗證觀察池的真實 1D K 線，於下一個 UTC 日 K 收盤後更新；不足兩個成分與共同期別者不繪製板塊泡泡。
- 回放的移動路徑依圖表設定開關，泡泡名稱使用無框、無粗描邊文字；主動買賣預設等大，並列出所有本期有效幣種，避免 BTC 成交額壓小其他幣的可見尺寸。
- 28/31 指的是 31 類中 28 類滿足至少兩個已驗證且有完整 K 線的成分。穩定幣／美元收益、Prediction Markets、DeSci 各只有一個有效合約；候選仍留在兩級清單，不能把單幣代表整個板塊。

## 互動與觀察模式修正

- 靜止時保留完整快照的圖面與刻度；背景逐筆更新只更新進度，首次沒有舊畫面才分批呈現。回放軌跡開關在設定內同時控制輪動與主動買賣，關閉後回放也不畫路徑。
- 點板塊泡泡或排行列會開啟有外框的板塊視窗，顯示指標、期別、歷史與已驗證成分幣。點成分幣數值列開啟含真實 K 線、漲跌及成交額的幣種詳情；點幣種名稱直接進入該幣雷達 K 線。主動買賣排行使用相同的兩種點擊，泡泡開啟幣種詳情。
- 主動買賣最多 50 個合約，支援成交額前 50、24H 漲幅前 50、既有雷達 OX 評分前 50；OX 未有評分不會虛構。資金異動模式在成交額前 50 觀察池內，以當期主動淨買額估算排序；不是完整市場大單灌入或入金。交易所主動成交每秒最多一個請求，首輪擴至 50 個合約需約一分鐘，已選清單可先顯示候選。

## 板塊與幣種彈出視窗修正

- 移除泡泡文字的 3px 黑色描邊；深色模式僅保留淡陰影，淺色模式使用純深色文字。
- 板塊彈窗保留清楚外框；幣種詳情疊在板塊上方，關閉或 Escape 回到原板塊。鍵盤 Enter／空白鍵可開啟成分列，幣名與「查看 K 線圖」直接導向主圖表。
- 幣種詳情共用既有 K 線畫布與 OXPublicFeed 排程，優先使用 15 秒內的主圖表行情。公共快取上限 24 組，11 個 K 線級別使用真實交易所資料，開啟期間每 15 秒更新。行情更新保留縮放與正在檢視的歷史範圍；詳情價格復用既有 ticker 串流，關閉停止該訂閱。關閉、隱藏或切換工具取消不再需要的工作，其他訂閱者的共用請求繼續。
- 每個請求讀取期限 12 秒；429 由既有排程最多重試一次。失敗停止定時重試並顯示手動重試，已有圖表保留並顯示最後成功的來源時間，重新連線可恢復。快速換級別使用版本與取消檢查阻止舊資料覆蓋新圖。
- 驗證：本地 build／check／來源保留驗證及 391 項測試通過。新增瀏覽器回歸覆蓋 320／390／1440px、深淺色、泡泡與排行、彈窗返回、快速換週期、名稱直達圖表及 429 手動恢復；CI 結果以 PR 檢查為準。手機尺寸模擬不是實體 iPhone 驗證。
